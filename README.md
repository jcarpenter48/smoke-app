# Smoke

[![Website](https://img.shields.io/badge/website-000000?style=for-the-badge&logo=About.me&logoColor=white)](https://droposs.org)
[![Docs](https://img.shields.io/badge/DOCS-black?style=for-the-badge&logo=docusaurus)](https://droposs.org/docs)

Smoke is a fork of Drop, the open-source game distribution platform, similar to GameVault or Steam. It's designed to distribute and share DRM-free games quickly, all while being flexible and fast.

> [!NOTE]
> Drop is in maintenance mode. Hence this private fork.

<div align="center">
<img src="https://droposs.org/_ipx/f_webp&q_80/images/carousel/store.png" alt="Drop Screenshot" width="900rem"/>

## Philosophy

1. Smoke is flexible. While abstractions and interfaces can complicate the codebase, the flexibility is worth it.
2. Smoke is secure. The nature of Smoke means an instance can never be accessible without authentication. In line with #1, Smoke also supports a huge variety of authentication mechanisms, from username/password to SSO.
3. Smoke is user-friendly. The interface is designed to be clean and simple to use, with advanced features available to users who want them.
